## The Share That Was Open All Year

A misconfigured file share has been serving student records to anyone on the internet. Nobody attacked anything — a permission was set for convenience and never set back.

This lab walks the whole response: classify what failed, find the service, contain it, justify the priority, fix the permission, and write the finding. Each step feeds the next, the way a real incident does.

<Callout type="exam">
Classification drives response, and that is why it comes first. A confidentiality failure drives containment and disclosure obligations. An availability failure drives restoration. An integrity failure drives verification against known-good copies. Get the classification wrong and every subsequent decision is aimed at the wrong problem.
</Callout>

<Callout type="warn">
The tempting move is to notify families immediately, because it feels like the responsible thing and it is visibly *doing something*. Done before containment, it announces a live exposure to an audience that now includes anyone who reads the message — while the share is still open. Contain first, then notify on the timeline regulation actually requires. Being fast and being first are not the same thing.
</Callout>
