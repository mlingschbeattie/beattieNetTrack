## The Anatomy of an Incident: Contain First, Investigate Second

In cybersecurity, perfection does not exist. Systems will get misconfigured, credentials will leak, and automated scripts will knock on open ports.

What separates a professional technician from an amateur is **Incident Triage Discipline**:
1. **Classification:** Identify which pillar of the CIA Triad has failed (Confidentiality, Integrity, or Availability).
2. **Containment:** Stop the bleeding immediately. Revoking an over-broad permission or isolating a compromised host must occur before drafting reports or attempting root-cause post-mortems.
3. **Telemetry Analysis:** Interrogate system logs (Windows Event Viewer Event 4625, syslog, audit trails) to discover how access was obtained.
4. **Remediation & Hardening:** Apply permanent controls (MFA, account lockout thresholds, BitLocker encryption, POSIX permission hardening).
5. **Documentation:** Write a clear, defensible closure note that satisfies auditors and executives.

<Callout type="exam">
CompTIA Tech+ FC0-U71 tests the fundamental incident response sequence: Containment must occur before eradication or recovery. Furthermore, understand the role of AAA: Authentication (MFA), Authorization (Access Control Lists / Least Privilege), and Accounting (Audit Event Logs).
</Callout>

<Callout type="warn">
Never attempt to 'clean up' or delete security event logs during an incident investigation! Deleting event logs destroys the forensic evidence required to determine whether data was exfiltrated. Always preserve logs and export them to a secure write-once syslog repository.
</Callout>
