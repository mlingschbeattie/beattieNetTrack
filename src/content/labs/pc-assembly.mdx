Use the simulator to choose compatible components and satisfy the generated scenario.

## Goals

- Match CPU socket, motherboard, and RAM generation correctly.
- Keep total cost under scenario budget.
- Resolve compatibility warnings before submitting.

## Lab Scenario

Each reset generates a new customer request with budget, workload targets, and minimum hardware requirements. Use the scenario summary in the workspace activity header while selecting parts.

## Learning Objectives

- Verify CPU, motherboard, and RAM compatibility constraints.
- Evaluate build quality against workload targets and budget.
- Use iterative validation before final submission.
