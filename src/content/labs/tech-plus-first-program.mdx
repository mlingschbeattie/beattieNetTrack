The loop is already written for you. Your job is the last two lines.

## Goal

Finish a working program that averages five test scores and prints the result. You will use three things the exam expects you to recognise: a **variable** that holds a value, a **loop** that repeats an action, and **output** that shows the result.

## What to do

The starter code adds every score into `total`. You need to divide that by how many scores there are, then print it. The output has to read exactly `Average: 78`.

## Why this matters

Tech+ does not ask you to write code from nothing, but it does expect you to read a short program and say what it does. Writing two lines yourself makes reading twenty far easier — and this is the loop, variable, and output pattern that nearly every exam code snippet is built from.
