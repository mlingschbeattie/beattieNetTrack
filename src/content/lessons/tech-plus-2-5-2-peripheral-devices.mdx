## Peripheral Devices

A peripheral is any hardware device that connects to — but is not part of — a computer's core processing components. Peripherals are categorized by direction of data flow.

### Input Devices

Input devices send data **into** the computer.

| Device | Function |
|---|---|
| Keyboard | Alphanumeric and command input |
| Mouse / Trackpad | Pointer control and clicking |
| Touchscreen | Combined input+output; touch input |
| Scanner | Digitizes physical documents to image/PDF |
| Webcam | Video/image capture |
| Microphone | Audio input |
| Barcode / QR scanner | Reads encoded labels |
| Biometric reader | Fingerprint, iris, or face for authentication |
| Gamepad / Joystick | Game input; also used in industrial controls |

### Output Devices

Output devices receive data **from** the computer.

| Device | Function |
|---|---|
| Monitor | Visual output; primary display |
| Printer | Produces physical copies of documents |
| Speakers / Headphones | Audio output |
| Projector | Large-format visual output |
| Braille display | Tactile output for visually impaired users |
| Plotter | Draws vector graphics on large paper (engineering/architecture) |

### Input/Output Devices

Some devices do both.

| Device | Input | Output |
|---|---|---|
| Touchscreen | Touch gestures | Display |
| Network interface | Receives packets | Transmits packets |
| External drive | Writes data | Reads data |
| VoIP headset | Microphone | Speakers |

### Printer Types

| Type | Technology | Best For |
|---|---|---|
| Laser | Toner + heat fuser | High-volume, sharp text |
| Inkjet | Liquid ink nozzles | Photos, color graphics |
| Thermal | Heat-sensitive paper | Receipts, labels (no ink) |
| 3D Printer | Additive material extrusion | Prototyping, fabrication |

### Key Exam Points

- Input = data INTO the computer; Output = data OUT of the computer
- A touchscreen is both input AND output
- Laser printers use **toner** (powder); inkjet printers use **liquid ink**
- Thermal printers require no ink — they burn an image onto special paper
