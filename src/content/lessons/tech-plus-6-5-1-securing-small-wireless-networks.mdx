## Securing the Invisible Airwaves

When you deploy a wired Ethernet network, an attacker must physically enter your building, plug a cable into a wall jack, or tap a copper wire to capture packets.

When you turn on a **Wireless Router**, radio waves pass effortlessly through drywall, glass windows, brick exterior walls, and out into the public parking lot.

An attacker sitting in a car 100 feet away with a high-gain antenna can attempt to intercept corporate emails, brute-force administrative passwords, and pivot onto your internal servers.

Understanding **Wireless Network Hardening** transforms an open, vulnerable radio bubble into an impenetrable enterprise boundary.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   WIRELESS ROUTER HARDENING CHECKLIST                  │
├────────────────────┬───────────────────────────────────────────────────┤

│                    │ Set a unique 16+ character Wi-Fi passphrase.      │
```

## 1. WPA3-SAE: The End of Offline Password Cracking

Why is **WPA3** so much stronger than legacy WPA2?

- **The Legacy WPA2 Flaw:** In WPA2, when a laptop connects to a router, it exchanges a 4-way authentication handshake. An attacker in the parking lot running *Wireshark* can capture that handshake packet, take it home to a powerful 8-GPU cracking rig, and run billions of password guesses per second offline without the router ever knowing!
- **The WPA3-SAE Revolution:** WPA3 uses **Simultaneous Authentication of Equals (SAE)** (also known as the *Dragonfly Handshake*). It uses zero-knowledge proof cryptography:
  - The password is never transmitted across the air.
  - An attacker cannot test passwords offline.
  - An attacker must guess passwords live against the router, where they will be instantly blocked after 5 failed attempts!

```
┌────────────────────────────────────────────────────────────────────────┐
│                      WIRELESS ENCRYPTION STANDARDS                     │
├──────────────┬───────────────┬─────────────────────────────────────────┤
│ Standard     │ Status        │ Cryptographic Reality                   │
├──────────────┼───────────────┼─────────────────────────────────────────┤
│ **WEP**      │ ❌ **DEAD**   │ Broken 64/128-bit RC4; cracked in 60 sec│
│ **WPA**      │ ❌ Deprecated │ Temporary patch; TKIP flaws             │
│ **WPA2**     │ ✔ Legacy Gold │ AES-CCMP; vulnerable to handshake capture│
│ **WPA3**     │ 🏆 **BEST**   │ SAE Dragonfly; immune to offline GPU    │
│              │               │ dictionary cracking                     │
└──────────────┴───────────────┴─────────────────────────────────────────┘
```

<Callout type="warn">
**The Deadly WPS PIN Backdoor:** **Wi-Fi Protected Setup (WPS)** was created to help non-technical users connect printers by entering an 8-digit PIN found on the router sticker. However, the WPS protocol validates the first 4 digits separately from the last 4 digits! This architectural flaw allows free tools (*Reaver*) to brute-force the PIN in less than 4 hours, displaying the plain-text Wi-Fi password. **Always disable WPS in router settings.**
</Callout>

## 2. Router Hardening: Locking the Admin Panel

1. **Change Default Credentials:** Attackers have automated scripts that scan IP addresses across the internet testing `admin/admin`, `admin/password`, and `root/toor`. Change the management password immediately upon unboxing.
2. **Disable Remote Management (WAN Access):** By default, management consoles should **only be accessible from internal LAN Ethernet ports**. Enabling remote management exposes the router's login page to every hacker on Earth.
3. **Keep Firmware Updated:** Router manufacturers release regular firmware updates to patch critical Linux kernel vulnerabilities and buffer overflows.

---

## 3. Network Segmentation: The Power of the Guest Network

Every modern home and office has smart IoT devices: smart lightbulbs, video doorbells, smart TVs, and networked coffee makers. 

Almost all IoT devices run cheap, unpatched software that is easily compromised by botnets.

**The Solution is Guest Isolation (VLAN Segmentation):**
- **Main Wi-Fi Subnet (`192.168.1.0/24`):** Corporate workstations, file servers, accounting databases, network printers.
- **Isolated Guest / IoT Subnet (`192.168.2.0/24`):** Visitors, smart TVs, IoT cameras, smartphones.
- Devices on the Guest network can reach the public internet, but **cannot see, ping, or communicate with devices on the Main subnet**.

## Why This Matters in the Field

When you set up a network for a small business, a medical clinic, or a home office, configuring wireless security properly protects your clients from devastating network breaches.

Enabling WPA3, disabling WPS, locking admin credentials, and segregating IoT devices on a guest network turns a basic router into a hardened security perimeter.
