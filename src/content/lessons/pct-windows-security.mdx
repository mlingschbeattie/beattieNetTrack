## 1. Authentication Architecture: TPM 2.0 and Windows Hello

Every security boundary in Windows starts with proving user identity:

```
┌────────────────────────────────────────────────────────────────────────┐
│                       THE 3 AUTHENTICATION FACTORS                     │
├────────────────────────┬───────────────────────────────────────────────┤
│ **1. Something You Know**│ Passwords, PINs, Security Questions.         │
├────────────────────────┼───────────────────────────────────────────────┤
│ **2. Something You Have**│ Smart Cards, USB Security Keys (YubiKey),    │
│                        │ Authenticator Apps (TOTP codes).              │
├────────────────────────┼───────────────────────────────────────────────┤
│ **3. Something You Are** │ Biometrics: Fingerprint, Facial Recognition, │
│                        │ Retina Scans.                                 │
└────────────────────────┴───────────────────────────────────────────────┘
```

### Why Windows Hello PINs Outperform Passwords
Many users ask: *"Why is a 6-digit PIN safer than a 14-character password?"*
- **Passwords:** Sent over the network to domain controllers or cloud servers. If an attacker intercepts the traffic or breaches the server database, they can use your password from Russia.
- **Windows Hello PIN:** **Never leaves the local computer.** It is bound to the motherboard's **TPM 2.0 (Trusted Platform Module)** chip. An attacker who steals your PIN cannot log into your account on any other machine!

## 3. The CompTIA 7-Step Malware Remediation Process

When an infection is discovered, execute this exact standard operating procedure:

1. **Step 1: Identify and Research Malware Symptoms**
   - Check Task Manager for unknown processes, high CPU/GPU spikes, or browser redirection loops.
2. **Step 2: Quarantine the Infected System**
   - **Immediately unplug the physical Ethernet cable and disconnect Wi-Fi!** This prevents ransomware from encrypting shared network drives or communicating with botnet command servers.
3. **Step 3: Disable System Restore**
   - In System Properties, turn off System Protection. If left enabled, Windows will save a backup snapshot containing the active virus, reinfecting the PC after reboot.
4. **Step 4: Remediate the Infected System**
   - Boot into **Safe Mode with Networking** or use an offline **Windows Defender Offline / WinRE USB**.
   - Update antivirus signatures and run complete deep scans.
   - Inspect startup entries with Microsoft Sysinternals *Autoruns*.
5. **Step 5: Schedule Scans and Run Updates**
   - Configure weekly automated scans and install all pending Windows security patches.
6. **Step 6: Enable System Restore and Create a Restore Point**
   - Turn System Protection back on and generate a pristine, clean baseline checkpoint.
7. **Step 7: Educate the End User**
   - Explain how the infection entered (e.g., clicking a fake email tracking link) to prevent repeat incidents.

## 4. Hardware-Rooted Disk Encryption: BitLocker & TPM

- **BitLocker Full Disk Encryption (FDE):** Scrambles 100% of the volume sectors using AES-128 or AES-256 encryption.
- **TPM 2.0 Integration:** BitLocker stores the decryption key in the motherboard's Trusted Platform Module. If a thief steals the physical SSD out of a corporate laptop, the drive cannot be read when plugged into another machine.
- **BitLocker Recovery Key:** A 48-digit emergency numeric password backed up to Active Directory or Microsoft Entra ID.
