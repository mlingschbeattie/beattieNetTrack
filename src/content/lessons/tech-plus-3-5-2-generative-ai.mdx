## Generative AI

**Generative AI** refers to AI systems that can create new content — text, images, audio, video, and code — rather than only classifying or analyzing existing content. It is the fastest-evolving area of AI and directly impacts how IT professionals work.

### What Is Generative AI?

Traditional AI: input data → classification or prediction output
Generative AI: input prompt → new content generated

Examples:
- Type a question → receive a detailed written answer
- Describe an image → receive a photorealistic generated image
- Describe a function → receive working code

### Large Language Models (LLMs)

LLMs are the technology behind text-generating AI tools. They are trained on massive amounts of text data and learn to predict what words (tokens) come next in a sequence.

**Notable LLMs and tools:**
| Tool | Developer | Primary Use |
|---|---|---|
| ChatGPT / GPT-4o | OpenAI | Conversational AI, writing, code |
| Gemini | Google | Multimodal AI (text, image, code) |
| Claude | Anthropic | Conversational AI, long documents |
| Copilot | Microsoft | M365 integration; coding assistant |
| GitHub Copilot | GitHub/Microsoft | Code completion and generation |
| LLaMA | Meta | Open-weight model; local deployment |

### Image Generation

- **DALL·E** (OpenAI), **Midjourney**, **Stable Diffusion**, **Adobe Firefly**
- Input: text prompt → output: photorealistic or artistic image
- Use cases: marketing materials, concept art, education illustrations, accessibility tools
- Concerns: deepfakes, copyright issues, spreading disinformation via fake images

### Code Generation

- GitHub Copilot, ChatGPT, Claude can generate, explain, and debug code
- Productivity boost for developers; lowers barrier to entry for learners
- Security concern: AI-generated code may contain vulnerabilities — always review output

### Capabilities

- Writing: drafting, summarizing, translating, proofreading
- Research assistance: synthesizing information on broad topics
- Code: generating boilerplate, explaining functions, debugging
- Image/audio/video: creating media from text descriptions
- Tutoring: step-by-step explanations adapted to the learner

### Limitations and Risks

| Issue | Description |
|---|---|
| **Hallucination** | LLMs confidently generate false facts; always verify critical information |
| **Training data cutoff** | Model knowledge is frozen at training date; recent events unknown |
| **Bias** | Reflects biases present in training data |
| **No true understanding** | Pattern prediction, not understanding — can fail on novel reasoning tasks |
| **Copyright** | Training data and generated content raise unresolved copyright questions |
| **Privacy** | Sensitive data entered as prompts may be used to train future models |

### Responsible Use

- **Verify outputs** — treat AI text as a first draft, not a final source
- **Do not input sensitive data** — PII, passwords, trade secrets should never go into a commercial AI prompt
- **Cite AI assistance** — many academic and professional contexts require disclosure
- **Review AI-generated code** before deploying — security vulnerabilities are common in generated code
- **Maintain human oversight** — critical decisions (medical, legal, financial) require human review

### AI in IT and Cybersecurity

- AI is being used to **generate phishing emails** — more convincing than ever
- AI is also being used to **detect threats** — anomaly detection, SIEM enrichment
- **Deepfakes** are used in social engineering — video calls and voice cloning impersonating executives
- Security teams use AI for **log analysis**, **vulnerability scoring**, and **incident triage**

### Key Exam Points

- Generative AI creates new content (text, images, code); traditional AI classifies existing content
- **LLMs** predict next tokens based on training data — they do not "understand"
- **Hallucination** = AI confidently producing false information — always verify
- Never input **PII, passwords, or confidential data** into commercial AI tools
- AI-generated code must be reviewed for security vulnerabilities before use
- Deepfakes and AI-generated phishing are active security threats
