## The Scale of Digital Storage

Every file on a computer—from a one-line Python script to a 100-gigabyte game install—is a collection of bytes stored on physical media.

As a technician, you need an instinctive feel for storage scale. If a user tells you their Word document is "50 Gigabytes," you know immediately that they are mistaken or attaching uncompressed raw video files. If an executive asks for a thumb drive to backup the company's 40-Terabyte file server, you can steer them toward a NAS or cloud backup before they waste money.

## Decimal (SI) vs. Binary (IEC) Prefixes

Almost every technician has had a client bring back an external hard drive and complain:

> *"I bought a 1 Terabyte SSD at Best Buy, but when I plugged it into Windows, it only says 931 GB! The store ripped me off!"*

The store didn't rip them off. The drive isn't missing 69 gigabytes. The discrepancy is caused by two different industries using two different mathematical definitions for the prefix **"kilo"**, **"mega"**, and **"giga"**.

### The Storage Vendor Math (Decimal / SI — Base-10)
Hard drive and flash memory manufacturers sell hardware using standard International System of Units (SI) metric prefixes:
- 1 Kilobyte (KB) = 10^3 = 1,000 bytes
- 1 Megabyte (MB) = 10^6 = 1,000,000 bytes
- 1 Gigabyte (GB) = 10^9 = 1,000,000,000 bytes
- 1 Terabyte (TB) = 10^{12} = 1,000,000,000,000 bytes

When Western Digital or Samsung manufactures a "1 TB" drive, they construct physical silicon that holds exactly **1,000,000,000,000 bytes**.

### The Operating System Math (Binary / IEC — Base-2)
Because computer memory addresses are binary, operating systems (like Windows) calculate capacity in powers of 2 (2^{10} = 1024):
- 1 Kibibyte (KiB) = 2^{10} = 1,024 bytes
- 1 Mebibyte (MiB) = 2^{20} = 1,048,576 bytes
- 1 Gibibyte (GiB) = 2^{30} = 1,073,741,824 bytes
- 1 Tebibyte (TiB) = 2^{40} = 1,099,511,627,776 bytes

### The Conversion:
When Windows scans that 1,000,000,000,000-byte drive, it divides by 1,073,741,824 (the number of bytes in a true binary gigabyte/GiB):

(1,000,000,000,000 bytes / 1,073,741,824 bytes/GiB) ≈ 931.32 GiB

Windows labels it "931 GB" on screen, which confuses users. Every single byte is physically there—it's just a difference in mathematical measurement.

## Real-World File Sizes and Estimation

When designing backup strategies or purchasing storage for clients, you need to estimate capacity quickly:

- **Plain Text Document (.txt):** 2 to 10 KB
- **Email with PDF Attachment:** 1 to 5 MB
- **High-Resolution Smartphone Photo (.jpg / .heic):** 3 to 8 MB
- **Compressed Music Track (MP3 @ 320kbps):** 8 to 12 MB
- **1 Hour of HD Video (1080p @ 30fps):** 3 to 5 GB
- **1 Hour of 4K Video (UHD @ 60fps):** 20 to 45 GB
- **Windows 11 OS Installation:** 25 to 35 GB
- **Modern AAA Game Install (Call of Duty, Cyberpunk):** 80 to 150 GB

## Bits vs. Bytes: Lowercase 'b' vs. Uppercase 'B'

This is the single most common marketing trap in consumer technology.

- **Lowercase `b` = Bits:** Used exclusively for **network transfer rates** and data in transit (e.g., 100 Mbps, 1 Gbps).
- **Uppercase `B` = Bytes:** Used exclusively for **static storage capacity** and file sizes (e.g., 500 MB, 2 TB).

Because there are **8 bits in 1 byte**, you must **divide network speeds by 8** to determine the actual file download rate:

(800 Megabits per second (Mbps) / 8 bits per byte) = 100 Megabytes per second (MB/s)

If a user with a "100 Mbps" internet connection tries to download an 800 MB video file, it does not take 8 seconds—it takes 800  MB \div 12.5 MB/s = 64 seconds.

## Why This Matters in the Field

When you size local storage for a security camera NVR (Network Video Recorder), plan cloud backup retention budgets, or specify drive capacities for an enterprise virtualization cluster, storage math translates directly into real hardware costs.

Understanding the difference between raw decimal bytes, binary operating system allocations, and transfer throughput prevents catastrophic storage shortages before systems go live.
