## Why Computers Think in Base-2

Humans count in **decimal (base-10)** because we were born with ten fingers. We use the digits 0 through 9, and when we run out of single digits, we roll over into a new column: 10, 100, 1000.

Computers do not have fingers. Inside a modern processor are billions of microscopic transistors made of silicon. A transistor is not a tiny calculator; it is an electronic switch. It can only be in one of two reliable physical states:

- **Switch Closed / Voltage Present:** Represented as **1**
- **Switch Open / No Voltage (Ground):** Represented as **0**

Trying to make transistors detect ten distinct voltage levels (0V, 0.5V, 1.0V... 4.5V) would make circuits fragile, slow, and prone to corruption from tiny electrical fluctuations. But distinguishing between *electricity flowing* versus *electricity blocked* is virtually bulletproof. This two-state system is called **binary (base-2)**.

```
┌──────────────────────────────────────────────────────────┐
│                   THE DIGITAL HIERARCHY                  │
├────────────┬─────────────┬───────────────────────────────┤
│ Unit       │ Size        │ What it Represents            │
├────────────┼─────────────┼───────────────────────────────┤
│ **Bit**    │ 1 binary bit│ Single switch (0 or 1)        │
│ **Nibble** │ 4 bits      │ One hexadecimal digit (0–F)   │
│ **Byte**   │ 8 bits      │ One ASCII character (0–255)   │
└────────────┴─────────────┴───────────────────────────────┘
```

A single **bit** (binary digit) can only tell you true/false or yes/no. But when you chain 8 bits together into a **byte**, you get 2^8 = 256 possible combinations (from `00000000` to `11111111`). That is enough combinations to represent every letter of the alphabet, every punctuation mark, every number from 0 to 255, or the red intensity of a single pixel on your monitor.

## Binary Place Values and the Power-of-2 Table

In decimal, every column moving right to left increases by a power of 10 (10^0 = 1, 10^1 = 10, 10^2 = 100, 10^3 = 1000).

In binary, every column moving right to left **doubles** as a power of 2 (2^0 = 1, 2^1 = 2, 2^2 = 4, 2^3 = 8). For an 8-bit byte, memorize this power-of-2 row cold:

| 2^7 | 2^6 | 2^5 | 2^4 | 2^3 | 2^2 | 2^1 | 2^0 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **128** | **64** | **32** | **16** | **8** | **4** | **2** | **1** |

The rightmost bit (2^0 = 1) is called the **Least Significant Bit (LSB)**. The leftmost bit (2^7 = 128) is called the **Most Significant Bit (MSB)**.

### Binary to Decimal: The Addition Rule

To convert any binary byte to decimal, write the byte under your power-of-2 chart and add up the values of every column that contains a **1**.

#### Example 1: Convert `11000000`
```
128   64   32   16    8    4    2    1
 1     1    0    0    0    0    0    0
--------------------------------------
128 + 64 = 192
```
*(Fun fact: `192.168.1.1` in your home router begins with this exact byte!)*

#### Example 2: Convert `10101011`
```
128   64   32   16    8    4    2    1
 1     0    1    0    1    0    1    1
--------------------------------------
128 + 32 + 8 + 2 + 1 = 171
```

<Callout type="tip">
**Quick Odd/Even Check:** Look at the LSB (the `1` column). If the last bit is `1`, the decimal number is guaranteed to be **odd** (128+64+32+16+8+4+2 are all even; only +1 makes it odd). If the last bit is `0`, the number is **even**.
</Callout>

## Decimal to Binary (The Technician's Subtraction Method)

In school you might have learned the division-by-2 method. In the server room or on a certification exam, technicians use the **Subtraction Method** because it is faster and can be calculated in your head.

**The Rule:** Ask: *"Is my number greater than or equal to the column value?"*
- If **YES**: Write down a `1`, subtract the column value, and take the remainder to the next column.
- If **NO**: Write down a `0` and move to the next column.

#### Step-by-Step: Convert Decimal `109` to Binary

1. Is 109 >= 128? **No** → **0** (Remainder: 109)
2. Is 109 >= 64? **Yes** → **1** (109 - 64 = 45)
3. Is 45 >= 32? **Yes** → **1** (45 - 32 = 13)
4. Is 13 >= 16? **No** → **0** (Remainder: 13)
5. Is 13 >= 8? **Yes** → **1** (13 - 8 = 5)
6. Is 5 >= 4? **Yes** → **1** (5 - 4 = 1)
7. Is 1 >= 2? **No** → **0** (Remainder: 1)
8. Is 1 >= 1? **Yes** → **1** (1 - 1 = 0)

**Result:** `01101101`

Double check: 64 + 32 + 8 + 4 + 1 = 109. Perfect.

## Encoding Text and Media into Binary

A CPU has no inherent concept of the letter "A", the color blue, or a song. Everything is assigned a numeric code:

- **ASCII (American Standard Code for Information Interchange):** Standardized table created in 1963. It assigns every keyboard key a number from 0 to 127:
  - Capital `'A'` = Decimal 65 → Binary `01000001`
  - Capital `'B'` = Decimal 66 → Binary `01000010`
  - Space bar = Decimal 32 → Binary `00100000`
- **Unicode / UTF-8:** Standard ASCII only supported 128 characters—enough for English, but useless for Japanese, Arabic, Greek, or emoji. Unicode expands character encoding up to 4 bytes (32 bits), supporting over 149,000 characters and symbols.
- **Images (RGB Pixels):** A color monitor displays pixels made of Red, Green, and Blue sub-pixels. In 24-bit TrueColor, each color channel gets 1 byte (values 0–255). Pure red is `255, 0, 0` (`11111111 00000000 00000000`).

<Callout type="exam">
For CompTIA Tech+, you are not expected to memorize the full ASCII chart, but you **must** understand that characters are encoded as numeric binary values (e.g. ASCII/Unicode) and that 1 Byte = 8 Bits = values 0 to 255.
</Callout>

## Why This Matters in the Field

When you configure IPv4 subnets, diagnose bit errors on serial cables, set file permission bitmasks in Linux (`chmod 777`), or troubleshoot Wi-Fi signal-to-noise ratios, you are interacting directly with binary boundaries.

A technician who doesn't understand binary is forced to memorize strings without understanding what they mean. A technician who knows binary sees `255.255.255.0` and immediately understands that the first 24 bits are locked to network routing, leaving 8 bits for host addressing. Master the powers of 2 now, and networking will make sense for the rest of your career.
