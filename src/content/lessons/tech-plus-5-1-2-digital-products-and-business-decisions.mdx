## Digital Products and Business Decisions

Modern organizations don't just collect data — they turn it into competitive advantage. Understanding how data drives products and decisions is increasingly expected even from entry-level IT staff, since infrastructure choices are shaped by how data is used.

### Digital Products

A **digital product** is any product delivered and experienced in digital form:
- Software applications (web apps, mobile apps, SaaS platforms)
- Digital content (streaming services, online courses, e-books)
- Digital services (online banking, cloud storage, GPS navigation)
- Data products (reports, dashboards, APIs delivering data to other systems)

**Data shapes digital products at every stage:**
- What features to build (based on usage data)
- How to personalize the experience (recommendations, adaptive content)
- When to release updates (based on bug data, user feedback)
- How to price tiers (based on usage patterns)

### Data-Driven Decision Making

Traditional decision making: intuition + experience → decision
Data-driven decision making: data + analysis → evidence → decision

Organizations that use data for decisions tend to:
- Catch problems earlier (anomaly detection)
- Allocate resources more accurately
- Reduce bias in hiring, operations, and product design
- Improve customer experience through personalization

### KPIs — Key Performance Indicators

A **KPI** is a measurable value that shows how effectively an organization, team, or process is achieving goals.

| Area | Example KPIs |
|---|---|
| **Business** | Revenue, profit margin, customer acquisition cost |
| **Web / App** | Page views, unique visitors, bounce rate, conversion rate |
| **Customer** | Customer satisfaction score (CSAT), Net Promoter Score (NPS) |
| **IT Operations** | System uptime %, mean time to repair (MTTR), ticket resolution time |
| **Security** | Mean time to detect (MTTD), number of incidents per month |
| **Education (LMS)** | Lesson completion rate, quiz pass rate, time-on-task |

KPIs without targets are just metrics. A KPI requires a target (e.g., "uptime > 99.9%") and regular measurement to be meaningful.

### Business Intelligence (BI)

**Business Intelligence (BI)** refers to the tools and processes that collect, analyze, and visualize organizational data to support decisions.

BI workflow:
1. **Data sources** — databases, spreadsheets, CRM systems, IoT sensors
2. **ETL (Extract, Transform, Load)** — data pulled from sources, cleaned, formatted, and loaded into a data warehouse
3. **Data warehouse** — central repository optimized for analysis (not transactions)
4. **BI tool** — queries the warehouse and presents visualizations and dashboards

**Common BI tools:**
- **Microsoft Power BI** — widely used; integrates with Microsoft 365
- **Tableau** — powerful visual analytics
- **Google Looker / Looker Studio** — cloud-native
- **Excel / Google Sheets** — entry-level; pivot tables, charts

### Dashboards and Reporting

A **dashboard** is a real-time visual display of KPIs and metrics. Examples:
- An IT manager's dashboard showing server uptime, help desk ticket queue, and network bandwidth
- A school LMS dashboard showing student completion rates and quiz averages by module

**Reports** are typically historical — a snapshot of data for a specific time period, used for review and planning.

### Data and Product Personalization

Platforms use collected data to personalize the user experience:
- Netflix recommends based on viewing history
- Amazon shows "recommended for you" based on purchase patterns
- Adaptive learning platforms (like beattieNetTrack) can adjust lesson difficulty based on quiz performance

### Privacy Consideration

Data-driven personalization requires collecting behavioral data. This creates tension with user privacy:
- Users receive better experiences but give up behavioral data
- Data minimization principle: collect only what is needed
- Always inform users what data is collected (privacy policy / GDPR/CCPA compliance)

### Key Exam Points

- **Digital products** are software/data services; data shapes what features to build and how to improve them
- **KPI** = measurable value tied to a specific goal; requires a target to be useful
- **Business Intelligence (BI)** = tools + process for turning raw data into actionable insight
- Common BI tools: Power BI, Tableau, Google Looker
- **Dashboard** = real-time KPI visualization; **Report** = historical analysis snapshot
- **ETL** = Extract, Transform, Load — the standard process for moving data into a data warehouse
