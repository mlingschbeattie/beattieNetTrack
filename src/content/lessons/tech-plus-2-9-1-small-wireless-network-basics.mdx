## The Invisible Network

Radio waves have replaced copper wires for billions of consumer devices. From smartphones and laptops to smart TVs and IoT security cameras, nearly every device in modern homes and small businesses connects via **Wi-Fi**.

However, radio frequency (RF) signals are unconstrained: they pass through walls, travel out into parking lots, and bounce off metal filing cabinets. A poorly configured wireless network will suffer from agonizingly slow speeds, constant dropped connections, and severe cybersecurity eavesdropping vulnerabilities.

Understanding Wi-Fi generations, frequency physics, channel allocation math, and cryptographic security protocols allows you to deploy fast, reliable, and secure wireless networks.


## 1. Frequency Bands: 2.4 GHz vs. 5 GHz vs. 6 GHz

Radio physics dictates a fundamental trade-off: **Higher frequencies carry more data, but have shorter physical range and poorer wall penetration.**

```
┌────────────────────────────────────────────────────────────────────────┐
│                        FREQUENCY BAND TRADEOFFS                        │
├────────────────────┬────────────────────┬──────────────────────────────┤
│ Frequency Band     │ Strengths          │ Weaknesses                   │
├────────────────────┼────────────────────┼──────────────────────────────┤
│ **2.4 GHz**        │ Long physical reach│ Crowded spectrum; extreme    │
│                    │ (through walls)    │ interference (Bluetooth,     │
│                    │                    │ microwaves); slow speeds     │
├────────────────────┼────────────────────┼──────────────────────────────┤
│ **5 GHz**          │ Blazing fast; 24   │ Shorter range; struggles to  │
│                    │ non-overlap channels│ penetrate brick/concrete    │
├────────────────────┼────────────────────┼──────────────────────────────┤
│ **6 GHz (6E / 7)** │ Ultra-wide clean   │ Shortest range; requires     │
│                    │ spectrum; 0 legacy │ line-of-sight or thin walls  │
└────────────────────┴────────────────────┴──────────────────────────────┘
```

### The 2.4 GHz Channel Mathematics (1, 6, 11)
In the 2.4 GHz band, there are 11 channels in North America. Each channel is 20 MHz wide, but channels are spaced only 5 MHz apart. This means adjacent channels overlap and cause severe radio interference:
- To prevent co-channel interference when deploying multiple access points, **technicians ONLY use Channels 1, 6, and 11**.

```
┌────────────────────────────────────────────────────────┐
│             2.4 GHz NON-OVERLAPPING CHANNELS           │
│                                                        │
│   [ Channel 1 ]       [ Channel 6 ]       [ Channel 11]│
│   (2.412 GHz)         (2.437 GHz)         (2.462 GHz)  │
│                                                        │
│   ✔ All other channels (2,3,4,5,7,8,9,10) overlap and   │
│     cause packet collisions!                           │
└────────────────────────────────────────────────────────┘
```

## 2. Wireless Security: Encryption Standards

Because Wi-Fi radio waves radiate beyond the walls of a building, encryption is mandatory to prevent attackers in parking lots from capturing passwords:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      WIRELESS SECURITY PROTOCOLS                       │
├──────────────┬───────────────┬─────────────────────────────────────────┤
│ Protocol     │ Security State│ Cryptographic Notes                     │
├──────────────┼───────────────┼─────────────────────────────────────────┤
│ **WEP**      │ ❌ **DEAD**   │ Broken 64/128-bit RC4; cracked in 60 sec│
│ **WPA**      │ ❌ Deprecated │ Temporary patch; TKIP vulnerabilities   │
│ **WPA2**     │ ✔ Enterprise  │ AES-CCMP encryption; standard legacy    │
│ **WPA3**     │ 🏆 **BEST**   │ SAE (Dragonfly) handshake; stops offline│
│              │               │ password dictionary cracking            │
└──────────────┴───────────────┴─────────────────────────────────────────┘
```

<Callout type="warn">
**The WPS Security Hazard:** **Wi-Fi Protected Setup (WPS)** was designed to help users connect printers by pushing a button or entering an 8-digit PIN. However, the WPS PIN architecture has a fatal design flaw that allows free automated attack tools (*Reaver*) to brute-force the PIN and reveal the plaintext Wi-Fi password in a few hours. **Always disable WPS on all routers.**
</Callout>

## 3. The 7-Step Small Office Wi-Fi Deployment Checklist

When unboxing and configuring a new wireless router or Access Point for a small business:
1. **Change Default Admin Passwords:** Replace `admin/password` or `admin/admin` immediately with a 16+ character passphrase.
2. **Assign a Professional SSID:** Set a descriptive network name (e.g. `AcmeCorp_Staff`), avoiding hardware brand names (`NETGEAR_5G`).
3. **Enable WPA3-Personal (or WPA2/WPA3 Mixed):** Never deploy WEP or open networks.
4. **Disable WPS:** Turn off Wi-Fi Protected Setup entirely.
5. **Create a Segregated Guest Network:** Put visitors and smart IoT TVs on an isolated Guest VLAN with no access to local corporate PCs or printers.
6. **Set Channel Allocation:** Manually set 2.4 GHz radios to Channels 1, 6, or 11; set 5 GHz to auto or uncrowded UNII bands.
7. **Update Firmware:** Flash the latest security firmware from the manufacturer to patch known vulnerabilities.

## Why This Matters in the Field

When a small business owner complains that their point-of-sale credit card terminals drop connection every time someone heats up lunch in the break room microwave, an untrained technician replaces the router.

A trained technician understands RF physics: microwave ovens leak 2.4 GHz radiation! Shifting the POS terminals to the **5 GHz band** solves the problem permanently.
