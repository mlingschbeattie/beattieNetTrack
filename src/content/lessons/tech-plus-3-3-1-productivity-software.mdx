## Productivity Software

Productivity software encompasses the applications that knowledge workers use to create, manage, and communicate information. Understanding the major suites and their components is foundational IT knowledge.

### The Major Productivity Suites

**Microsoft 365 (formerly Office)**
- The dominant enterprise productivity platform
- **Word** — word processor; `.docx` format
- **Excel** — spreadsheet; `.xlsx` format; formulas, charts, pivot tables
- **PowerPoint** — presentations; `.pptx` format
- **Outlook** — email, calendar, contacts, tasks
- **OneNote** — digital notebook
- **Teams** — communication and collaboration (chat, video, file sharing)
- Available as desktop apps, web apps (Office Online), and mobile apps

**Google Workspace (formerly G Suite)**
- Cloud-first; browser-based; free tier available
- **Docs** — word processor (compatible with .docx)
- **Sheets** — spreadsheet (compatible with .xlsx)
- **Slides** — presentations (compatible with .pptx)
- **Gmail** — email
- **Calendar** — scheduling
- **Drive** — cloud storage and file sharing
- **Meet** — video conferencing

**LibreOffice / OpenOffice**
- Free, open-source office suite
- Writer, Calc, Impress, Base, Draw
- Compatible with Microsoft formats; common in schools and Linux environments

### Software Licensing Models

| Model | Description | Examples |
|---|---|---|
| **Subscription** | Pay monthly/annually; always up to date | Microsoft 365, Adobe Creative Cloud |
| **Perpetual license** | One-time purchase; specific version forever | Office 2021 (standalone) |
| **Freeware** | Free to use; closed source | Irfanview, VLC |
| **Open source** | Source code available; often free | LibreOffice, Firefox, GIMP |
| **SaaS** | Web-based; no install required | Google Workspace, Salesforce |

### PDF Tools

PDF (Portable Document Format) is the universal document exchange format:
- **Adobe Acrobat** — full creation/editing (paid)
- **Adobe Acrobat Reader** — free PDF viewer
- **Foxit Reader** — lightweight free alternative
- **Built-in OS support:** Windows 11, macOS, and modern browsers can open PDFs natively
- **Print to PDF:** Every modern OS includes a virtual PDF printer — print any document to PDF without software

### File Format Compatibility

A common help-desk issue: a user can't open a file. Common causes:
- Wrong application installed for that format
- Older version of software (e.g., Office 2010 can't open some `.docx` features from 365)
- File is corrupt or was created by unsupported software

**Solution path:** Identify the file extension → install or update the appropriate application → if conversion needed, use a converter or open in an online service.

### Key Exam Points

- Microsoft 365 = subscription model; Office 2021 = perpetual license
- Google Workspace is cloud-first; Microsoft 365 offers both desktop and cloud
- **SaaS** productivity tools (Google Workspace, Microsoft 365 web) run in the browser — no local install required
- Open source ≠ free — but LibreOffice and OpenOffice are both free AND open source
- PDF is platform-neutral; any OS can open a PDF in a browser or built-in viewer
