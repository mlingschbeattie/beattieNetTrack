## When the Operating System Crashes

A client's desktop displays the dreaded **Blue Screen of Death (BSOD)** with a sad face emoji:

`Stop Code: IRQL_NOT_LESS_OR_EQUAL`  
`What failed: nvlddmkm.sys`

The user is convinced their hard drive is physically melting.

Amateurs react to software crashes by immediately wiping the hard drive and reinstalling Windows from scratch—wasting hours of time and destroying client applications.

Professional technicians read the clues left behind by the operating system kernel.

Windows logs every crash, records the exact faulting driver name, generates **Minidump files**, and provides surgical repair utilities like **SFC**, **DISM**, and **Event Viewer**.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        SOFTWARE TRIAGE DECISION LADDER                 │
```

## 2. Reading the Blue Screen of Death (BSOD)

When the Windows kernel encounters an unrecoverable error, it halts execution to protect data integrity:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        COMMON BSOD STOP CODES                          │
├──────────────────────────────┬─────────────────────────────────────────┤
│ Stop Code                    │ Most Common Root Cause                  │
├──────────────────────────────┼─────────────────────────────────────────┤
│ `IRQL_NOT_LESS_OR_EQUAL`     │ Driver accessing invalid memory addresses│
│                              │ (Driver bug or failing RAM modules).    │
├──────────────────────────────┼─────────────────────────────────────────┤
│ `SYSTEM_SERVICE_EXCEPTION`   │ Kernel-mode driver crash (e.g. GPU).    │
├──────────────────────────────┼─────────────────────────────────────────┤
│ `PAGE_FAULT_IN_NONPAGED_AREA`│ System requested memory page that is not│
│                              │ present in RAM (Faulty RAM or SSD bad). │
├──────────────────────────────┼─────────────────────────────────────────┤
│ `CRITICAL_PROCESS_DIED`      │ Vital Windows process (`csrss.exe` or   │
│                              │ `wininit.exe`) terminated unexpectedly. │
├──────────────────────────────┼─────────────────────────────────────────┤
│ `WHEA_UNCORRECTABLE_ERROR`   │ Hardware failure (overheating CPU or    │
│                              │ unstable voltage).                      │
└──────────────────────────────┴─────────────────────────────────────────┘
```

### Analyzing Minidumps with WinDbg
Whenever a BSOD occurs, Windows dumps the contents of crash memory into:  
`C:\Windows\Minidump\*.dmp`

Technicians open minidumps using tools like **WinDbg** or **BlueScreenView** to immediately find the line:  
`Probably caused by: nvlddmkm.sys (Nvidia Graphics Driver)`

Once you know the file, you boot into Safe Mode, open **Device Manager (`devmgmt.msc`)**, right-click the device, and select **Roll Back Driver**!

## 3. Surgical Repairs: DISM and SFC

When Windows acts erratically, files are missing, or icons glitch, run the two-punch command line repair:

```
┌────────────────────────────────────────────────────────┐
│            THE DISM + SFC INTEGRITY SEQUENCE           │
│                                                        │
│   Step 1: Fix the Master Component Store via Internet  │
│   `DISM /Online /Cleanup-Image /RestoreHealth`         │
│                                                        │
│   Step 2: Scan & Replace Corrupted System Files        │
│   `sfc /scannow`                                       │
└────────────────────────────────────────────────────────┘
```

<Callout type="exam">
**Why Run DISM Before SFC?** `sfc /scannow` inspects Windows system files against the local **Windows Component Store (`WinSxS`)**. If the Component Store itself is corrupted, SFC cannot fix files! Running `DISM /RestoreHealth` first downloads clean source files from Microsoft Update, allowing SFC to successfully repair the system.
</Callout>

## 4. Recovering Stuck Windows Updates

When Windows Update hangs at `Downloading 0%` or fails with error `0x80070002`, the local update download cache is corrupted.

Execute the cache purge in an Administrative Command Prompt:
```cmd
net stop wuauserv
net stop bits
rd /s /q C:\Windows\SoftwareDistribution\Download
net start wuauserv
net start bits
```

## 5. Event Viewer Logs (`eventvwr.msc`)

Event Viewer is the black-box flight recorder of Windows:
- **System Log:** Records driver failures, hardware warnings, and kernel crashes.
- **Application Log:** Records crashes and errors generated by installed software (e.g. Word, Chrome).
- **Security Log:** Records successful and failed login attempts (Audit failures).

Filter logs by **Event Level: Critical and Error** to see exactly what failed at the timestamp of the client's crash.
