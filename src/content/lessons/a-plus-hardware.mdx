Hardware is the physical stuff you can touch in a computer -- like organs in a body, each part has a specific job and they all work together. Understanding what each component does and how they connect is the foundation of A+ certification and real-world PC support.

## Key Components

| Component | Role |
|---|---|
| **CPU (Processor)** | The "brain" -- executes all instructions and calculations |
| **RAM (Memory)** | Fast, temporary storage for programs currently running |
| **Motherboard** | Main circuit board -- connects and coordinates everything |
| **PSU (Power Supply Unit)** | Converts AC wall power to DC voltages the components need |
| **Storage (HDD/SSD)** | Permanent data storage for the OS, apps, and files |
| **GPU (Graphics Card)** | Handles display rendering; optional if CPU has integrated graphics |

## CPU Characteristics

| Characteristic | What It Means |
|---|---|
| **Clock Speed (GHz)** | Operations per second -- higher generally means faster |
| **Cores** | Independent processing units; more cores = better multitasking |
| **Cache (L1/L2/L3)** | Ultra-fast on-chip memory to reduce trips to RAM |
| **TDP (Thermal Design Power)** | Heat output in watts -- drives cooling requirements |
| **Socket Type** | Physical CPU-to-motherboard interface (e.g., LGA 1700, AM5) |
| **Threads** | Logical cores via hyperthreading -- a 4-core/8-thread CPU handles 8 simultaneous tasks |

## RAM Deep Dive

| Concept | Details |
|---|---|
| **DRAM vs SRAM** | Dynamic (common, cheap) vs Static (fast, expensive -- used for cache) |
| **DDR Generations** | DDR4 is current standard; DDR5 offers higher speeds and bandwidth |
| **Capacity** | Measured in GB -- how much data can be held in memory at once |
| **Speed** | Measured in MHz (or MT/s) -- higher is better; must match motherboard support |
| **Volatile** | RAM loses all data when power is removed -- it is NOT permanent storage |
| **Dual-Channel** | Install RAM in matched pairs in the correct slots for ~10-15% bandwidth gain |

## Storage Types

| Type | Interface | Speed | Notes |
|---|---|---|---|
| **HDD (Hard Disk Drive)** | SATA | ~100-200 MB/s | Spinning platters; cheap per GB; fragile |
| **SATA SSD** | SATA | ~500 MB/s | Solid state; fast boot; drop-in HDD replacement |
| **NVMe SSD** | PCIe (M.2) | 3,000-7,000 MB/s | Fastest consumer storage; connects directly on board |
| **Optical Drive** | SATA | ~50 MB/s | CD/DVD/Blu-ray; increasingly rare |

## Common Ports & Peripherals

| Port | Purpose |
|---|---|
| **USB 2.0** | 480 Mbps -- mice, keyboards, low-speed devices |
| **USB 3.x** | 5-20 Gbps -- fast flash drives, external SSDs |
| **USB4 / Thunderbolt** | Up to 40 Gbps over USB-C; supports video and data simultaneously |
| **HDMI** | Digital video + audio; most common monitor/TV connector |
| **DisplayPort** | Digital video; supports daisy-chaining multiple monitors |
| **Ethernet (RJ-45)** | Wired network connection |
| **3.5mm Audio** | Analog mic/headphone jack |
| **Bluetooth / Wi-Fi** | Wireless peripherals and networking (integrated or PCIe card) |

## Display Standards & Panel Types

| Panel Type | Strengths | Weaknesses |
|---|---|---|
| **TN (Twisted Nematic)** | Fastest response time (1ms) | Poor color accuracy, narrow viewing angles |
| **IPS (In-Plane Switching)** | Best color accuracy and wide viewing angles | Slightly slower, higher cost |
| **VA (Vertical Alignment)** | Best contrast ratio | Middle ground on speed and angles |
| **OLED** | Perfect blacks, per-pixel lighting | Burn-in risk, higher cost |

### Common Resolutions

| Name | Pixels | Common Use |
|---|---|---|
| **1080p (Full HD)** | 1920 x 1080 | Standard desktop monitor |
| **1440p (QHD)** | 2560 x 1440 | Gaming and productivity |
| **4K (UHD)** | 3840 x 2160 | High-end monitors and TVs |

**Key display specs**: Refresh rate (Hz) -- 60 Hz standard, 144+ Hz for gaming. Response time (ms) -- lower reduces motion blur. HDR -- wider contrast and color depth.

## Laptop & Mobile Hardware

| Feature | Notes |
|---|---|
| **SO-DIMM RAM** | Smaller laptop memory module form factor (vs desktop DIMM) |
| **M.2 SSD** | Most common laptop storage upgrade slot |
| **Battery Types** | Lithium-ion (Li-ion) and Lithium-polymer (LiPo) |
| **Display Types** | TN vs IPS; common resolutions 1080p/1440p |
| **Docking Stations** | Expand ports and add external displays via USB-C/Thunderbolt |
| **Touch & Stylus** | Digitizer layer added on top of standard display stack |

## Expansion Cards & Buses

| Card / Bus | Purpose |
|---|---|
| **PCIe x16** | Primary GPU slot (highest bandwidth) |
| **PCIe x1 / x4** | NICs, sound cards, capture cards, USB expansion cards |
| **NIC (Network Interface Card)** | Adds wired or wireless networking |
| **Sound Card** | Enhanced audio processing beyond onboard audio |
| **Legacy PCI** | Older expansion standard -- obsolete but may appear on exam |

## Exam Essentials

- A CPU with 4 cores and 8 threads can handle **8 operations simultaneously**
- RAM is **volatile** -- data is lost on power off; it is NOT permanent storage
- **DDR4** is the current standard; DDR5 is the emerging successor
- Thermal paste ensures proper heat transfer between CPU and heatsink
- PSU wattage rating should be **20-30% above** total system draw (headroom)
- Case fans: intake pulls cool air in from front/bottom; exhaust pushes hot air out the rear/top
- **DisplayPort** supports daisy-chaining; **HDMI** does not (natively)
- **SO-DIMM** is the laptop RAM form factor; **DIMM** is desktop
- NVMe SSDs connect via an **M.2 slot** and the **PCIe bus** -- not SATA

## Practical Exercises

1. **Component Hunt** -- Open a PC (or examine a diagram) and label: CPU, RAM DIMMs, PSU, GPU, storage devices
2. **RAM Seating Check** -- Verify dual-channel placement using motherboard slot markings (usually A2/B2 for 2-stick kits)
3. **CPU Spec Compare** -- Compare two CPUs side-by-side: core count, clock speed, TDP, cache, socket, price
4. **PSU Wattage Estimate** -- Add up wattage for CPU + GPU + drives + fans, then add 20-30% headroom
5. **Monitor Spec Read** -- Find a monitor's spec sheet; identify panel type, resolution, refresh rate, and response time
