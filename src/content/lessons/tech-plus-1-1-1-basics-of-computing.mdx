## Basics of Computing

A **computer** is an electronic device that accepts input, processes it according to instructions, and produces output — storing data along the way. This four-part model (Input → Process → Output → Storage) applies to every computing device from a smartphone to a supercomputer.

### The IPO+S Model

| Stage | Description | Examples |
|---|---|---|
| **Input** | Data entering the system | Keyboard, mouse, microphone, camera, scanner, touchscreen, sensor |
| **Process** | CPU executes instructions on data | Arithmetic, logic, sorting, rendering, encryption |
| **Output** | Results delivered to the user or environment | Monitor, speakers, printer, motor, network transmission |
| **Storage** | Data retained for later use | RAM (short-term), SSD/HDD (long-term), cloud |

### Hardware vs. Software

**Hardware** — the physical components you can touch:
- CPU, RAM, motherboard, storage drives, GPU, power supply
- Input and output devices
- Network adapters, cables, connectors

**Software** — instructions that tell hardware what to do:
- **System software** — operating system, device drivers, firmware (runs the hardware layer)
- **Application software** — programs users interact with (Word, Chrome, Minecraft)
- **Utility software** — maintenance tools (antivirus, disk cleanup, backup agents)

Hardware without software is inert. Software without hardware has nothing to run on. Together they form a working computer system.

### Categories of Computing Devices

**Personal Computer (PC)**
- Desktop or laptop; general-purpose; runs full OS
- Examples: Windows PC, Mac

**Mobile Device**
- Smartphone, tablet; touch-first; battery-constrained
- Examples: iPhone, Android phone, iPad

**Server**
- Provides services to other computers on a network
- Optimized for reliability and multi-user access; often headless (no monitor)

**Embedded Computer**
- Specialized, single-purpose device; minimal UI
- Examples: smart thermostat, ATM, car engine controller, smart TV

**Wearable**
- Body-worn computing; very constrained form factor
- Examples: smartwatch, fitness tracker, AR glasses

**Mainframe**
- Large-scale enterprise system; handles thousands of simultaneous transactions
- Common in banking, insurance, government

**Supercomputer**
- Extreme parallel processing for scientific workloads
- Used in weather modeling, genomics, physics simulation

### Analog vs. Digital

- **Analog** — continuous signal (e.g., vinyl record, traditional thermometer)
- **Digital** — discrete values, represented as 0s and 1s
- Computers are fundamentally digital — all data is encoded as binary

### Why This Matters

Every IT decision traces back to these basics: what is the input source? what processes it? what are the output requirements? what storage is needed? Understanding the model prevents mismatched solutions — like recommending a desktop when a mobile-first workflow is needed.

### Key Exam Points

- IPO+S model: **Input → Process → Output → Storage**
- **Hardware** = physical; **Software** = instructions
- System software (OS/drivers) sits between hardware and applications
- Embedded computers are single-purpose; servers serve other computers on a network
- All computing is fundamentally **digital** — data is always binary (0s and 1s) at the lowest level
