Troubleshooting is like being a detective -- you gather clues, narrow down suspects, test theories, and fix the root cause. The goal is not just to make it work; it's to find *what* went wrong so you can prevent it next time.

## The CompTIA 7-Step Diagnostic Process

This is the official A+ troubleshooting methodology. Know all 7 steps and their order.

```
Step 1: Identify the problem
   - Ask questions, document symptoms, review error messages, gather logs

Step 2: Establish a theory of probable cause
   - Use experience and knowledge to hypothesize the root cause
   - Start with the simplest/most likely explanation first

Step 3: Test the theory to determine cause
   - Run diagnostic tools, swap components, test the hypothesis
   - If theory is confirmed -> move to step 4
   - If disproved -> form a new theory (back to step 2)

Step 4: Establish a plan of action to resolve the problem
   - Create a fix plan, consider side effects and impact on users

Step 5: Implement the solution or escalate as necessary
   - Apply the fix; if beyond your scope/permissions, escalate

Step 6: Verify full system functionality
   - Test everything -- confirm the original problem is solved
   - Check for new issues introduced by the fix

Step 7: Document findings, actions, and outcomes
   - Write detailed notes: date, symptoms, cause, fix, result
```

## Common Hardware Issues & Fixes

| Symptom | Likely Causes | First Steps |
|---|---|---|
| **No Power** | PSU failure, loose cables, bad outlet | Check wall outlet, reseat power cables, test PSU |
| **No Display** | Loose cable, failed GPU, bad RAM | Check monitor cable, reseat RAM and GPU |
| **Overheating / Shutdowns** | Thermal paste dried, clogged fans | Clean dust, reapply thermal paste, check fan operation |
| **POST Beep Codes** | Hardware fault detected during POST | Consult motherboard manual -- continuous beeps often = RAM |
| **Intermittent Crashes / BSOD** | Bad RAM, failing PSU, overheating | Run memory test (MemTest86), check Event Viewer |
| **Slow Performance** | CPU/RAM maxed, dying drive | Check Task Manager, run disk health check (SMART) |

## Software Troubleshooting Tools (Windows)

| Tool | Purpose |
|---|---|
| **Task Manager** | Monitor processes, CPU/RAM usage, kill hung apps, manage startup |
| **Device Manager** | Check driver status; yellow ! = driver problem |
| **Event Viewer** | System, Application, and Security logs -- find error codes |
| **Disk Management** | Partition, format, and resize drives |
| **System Restore** | Roll back Windows to a previous stable restore point |
| **Safe Mode** | Boot with minimal drivers/services -- isolate software vs hardware |
| **Resource Monitor** | Detailed CPU, memory, disk, and network activity |
| **SFC / DISM** | Repair corrupted Windows system files |

## Common Software Issues

| Issue | Typical Cause | Resolution |
|---|---|---|
| **Slow Boot** | Too many startup apps, failing disk | Disable startup items in Task Manager; run disk health check |
| **Application Crash** | Outdated app, corrupted install | Check for updates; check Event Viewer; reinstall |
| **Blue Screen (BSOD)** | Driver bug, RAM fault, hardware failure | Note error code; check recent driver installs; run MemTest86 |
| **No Internet** | IP misconfiguration, DNS failure, router issue | Run ipconfig/ipconfig /renew; check router; ping gateway |
| **Printer Not Working** | Driver, spooler, connectivity | Restart Print Spooler service; reinstall driver |

## Recovery & Backup Strategies

| Strategy | Description |
|---|---|
| **File Backup** | Copies of documents, photos, and data files |
| **Image Backup** | Full system snapshot (entire drive) -- fastest full restore |
| **Incremental Backup** | Only changes since last backup -- fast, small |
| **Differential Backup** | All changes since last full backup -- faster restore than incremental |
| **Cloud Backup** | Offsite via OneDrive, Google Drive, Backblaze |
| **Test Restore** | Periodically verify that backups can actually be restored |

### The 3-2-1 Backup Rule

```
3 copies of data
2 different media types (e.g., local drive + external drive)
1 offsite copy (cloud or physical location)
```

## Printer Troubleshooting

| Problem | Cause | Fix |
|---|---|---|
| **Paper Jam** | Misaligned paper, worn rollers | Remove paper gently; check rollers and tray alignment |
| **Low Ink / Toner** | Cartridge empty | Replace cartridge; run calibration/alignment |
| **Wrong Driver** | Incorrect model installed | Uninstall and reinstall the correct driver |
| **Jobs Stuck in Queue** | Print Spooler hung | Restart the Print Spooler service (services.msc) |
| **Connectivity** | USB loose, Wi-Fi drop, wrong IP | Check physical connection; verify IP in printer settings |
| **Ghost Images / Streaks** | Dirty drum or low toner | Clean drum; replace ink/toner; check fuser unit |

## Mobile Device Issues

| Issue | First Steps |
|---|---|
| **Battery Draining Fast** | Check background apps and screen brightness; check battery health |
| **Overheating** | Close apps, remove case, move to cool area |
| **Storage Full** | Clear app cache, remove unused apps, offload to cloud |
| **No Signal / Calls Dropping** | Toggle airplane mode; check SIM seating; network settings reset |
| **App Crashes** | Update or reinstall the app |
| **Won't Update OS** | Free up storage, ensure battery >50%, retry on Wi-Fi |

## Ticketing, SLA & Escalation

| Concept | Details |
|---|---|
| **Ticket Notes** | Record symptoms, steps taken, and results -- always timestamped |
| **SLA Priority** | Set urgency (impact + number of users affected) |
| **Escalation** | Hand off when the issue is beyond your scope, permissions, or expertise |
| **User Communication** | Provide status updates; confirm with user when resolved |

## Preventive Maintenance Schedule

```
Weekly:
  - Clear temp files (Disk Cleanup / Storage Sense)
  - Check Task Manager for runaway processes

Monthly:
  - Update Windows and drivers
  - Scan for malware
  - Defragment HDDs (NOT SSDs -- SSDs self-optimize)

Quarterly:
  - Clean internal dust (fans, heatsinks, vents)
  - Check drive health with SMART diagnostics
  - Review and test backup status

Annually:
  - Replace thermal paste on CPU heatsink
  - Upgrade OS if new version available
  - Audit and remove unused software
```

## Exam Critical Facts

- **Always document** -- dates, times, symptoms, steps taken, and outcomes
- Follow the 7-step process **in order** -- don't skip to solutions
- **Don't assume** -- test every theory before acting on it
- **Escalate** when the issue is beyond your scope or permissions
- **Prioritize data safety** before experimenting with fixes
- Know the difference: **symptom** (what the user sees) vs **cause** (root problem)
- Always back up before major changes
- BSOD error codes tell you *which driver or component* failed -- look them up
- `sfc /scannow` repairs corrupted Windows system files
- `DISM /Online /Cleanup-Image /RestoreHealth` repairs the Windows image itself
