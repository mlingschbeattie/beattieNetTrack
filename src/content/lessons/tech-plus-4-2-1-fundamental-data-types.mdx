## The Building Blocks of Program Memory

In computer programming, a computer does not view data as an abstract concept. Every piece of information—a user's password, a bank account balance, a high score, or a network IP address—must be stored in physical RAM transistors.

To know how many bytes of memory to reserve and what operations are legally permitted on that data, the programming language assigns each value a **Data Type**.

You cannot multiply a street address by 5, and you cannot spell-check a decimal temperature. Understanding data types allows you to prevent software crashes, eliminate type mismatch bugs, and manage memory effectively.

```
┌────────────────────────────────────────────────────────────────────────┐
│                      THE CORE PRIMITIVE DATA TYPES                     │
├───────────────────┬────────────────────┬───────────────────────────────┤
│ Data Type         │ Typical Values     │ Ideal Real-World Use Case     │
├───────────────────┼────────────────────┼───────────────────────────────┤
│ **Integer (int)** │ `0`, `42`, `-15`   │ User counts, age, loop indexes│
├───────────────────┼────────────────────┼───────────────────────────────┤
│ **Float / Double**│ `3.14`, `-0.05`    │ Sensor readings, measurements │
├───────────────────┼────────────────────┼───────────────────────────────┤
│ **String (str)**  │ `"Beattie"`, `"IT"`│ Usernames, emails, file paths │
├───────────────────┼────────────────────┼───────────────────────────────┤
```

## 1. Numeric Types: Integers vs. Floating-Point Numbers

Computers divide numbers into two distinct mathematical categories:

### Integers (`int`) — Whole Numbers
- **What they are:** Whole numbers without decimal fractions (`-500`, `0`, `1`, `2026`).
- **Memory Allocation:** Standard 32-bit signed integers range from $-2,147,483,648$ to $+2,147,483,647$. Modern 64-bit integers scale to 9 quintillion.
- **Use Cases:** Counting items, array position indexes, employee ID numbers.

### Floating-Point Numbers (`float` / `double`) — Decimals
- **What they are:** Numbers that include decimal points (`3.14159`, `-10.5`, `0.001`).
- **Single Precision (`float`):** Uses 32 bits of memory (~7 decimal digits of precision).
- **Double Precision (`double`):** Uses 64 bits of memory (~15 decimal digits of precision).
- **The Binary Decimal Flaw:** In binary floating-point math (IEEE 754), certain decimal fractions like `0.1` or `0.2` cannot be cleanly represented in base-2 binary. When you calculate `0.1 + 0.2` in Python or JavaScript, the computer outputs `0.30000000000000004`!

<Callout type="warn">
**The Financial Math Rule:** Because floating-point numbers have microscopic precision rounding errors, enterprise financial banking software **never uses floats for currency**. Instead, banks store money as **Integers in Cents** ($10.50 is stored as integer `1050`) or use specialized exact decimal libraries!
</Callout>

## 2. Textual Types: Characters vs. Strings

### Character (`char`)
- A single alphanumeric letter, punctuation mark, or space (e.g., `'Y'`, `'N'`, `'%'`).
- Under the hood, characters are stored as integer values defined by **ASCII** (e.g. `'A'` is ASCII integer `65`) or **Unicode UTF-8**.

### String (`str`)
- An ordered collection of characters enclosed in quotation marks: `"Network Engineer"`.
- **String Concatenation:** Joining two strings together using the `+` operator:
  - `"Cyber" + "security"` $\rightarrow$ `"Cybersecurity"`

## 3. Boolean Logic & The Concept of Null

### Boolean (`bool`)
- Named after mathematician George Boole. A boolean can evaluate to only two possible states: **`True`** (binary 1) or **`False`** (binary 0).
- Booleans drive all programmatic decision-making:
  ```python
  is_logged_in = True
  account_locked = False

  if is_logged_in and not account_locked:
      grant_dashboard_access()
  ```

### Null / None / Nil (The Void)
- `Null` does not mean `0` (which is a valid number), and it does not mean `""` (which is a valid empty string).
- `Null` means **the total absence of a value**. When an employee is first created in a database before taking their first test, their `exam_score` variable is initialized to `Null`.

## 4. Type Casting: Converting Between Types

Programs constantly need to transform data from one type to another:

```
┌────────────────────────────────────────────────────────┐
│             EXPLICIT TYPE CASTING EXAMPLES             │
│                                                        │
│   String to Integer:  int("42")       ──> 42 (int)     │
│   Integer to String:  str(100)        ──> "100" (str)  │
│   String to Float:    float("19.99")  ──> 19.99 (float)│
│   Integer to Float:   float(5)        ──> 5.0 (float)  │
└────────────────────────────────────────────────────────┘
```

### The Classic Type Mismatch Bug
When a user types their zip code into a website form, the web browser sends the value as a **String (`"15237"`)**, not an integer. If the programmer attempts to calculate mathematical shipping distances without type casting the string to a numeric integer, the program will crash with a **Type Error**.
