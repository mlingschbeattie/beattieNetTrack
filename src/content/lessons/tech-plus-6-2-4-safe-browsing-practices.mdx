## Navigating the Wild Web

For most computer users, the **Web Browser** is the operating system: it is where they check email, perform online banking, manage cloud databases, and stream entertainment.

Because users spend 90% of their digital time inside a browser, it is also the primary attack vector for cybercriminals.

From fraudulent phishing domains disguised with lookalike characters to unpatched browser exploits that execute code without a single click, understanding **Safe Browsing Practices** is a vital defensive skill for every technician.

## 1. The Great HTTPS Padlock Myth

In the early days of the web, cybersecurity experts taught users a simple rule: *"Look for the green padlock in the address bar! If you see the padlock, the website is completely safe!"*

**That rule is now dangerously obsolete.**

```
┌────────────────────────────────────────────────────────────────────────┐
│                      WHAT THE HTTPS PADLOCK ACTUALLY MEANS             │
├──────────────────────────────────┬─────────────────────────────────────┤
│ ✔ **WHAT HTTPS GUARANTEES:**     │ ❌ **WHAT HTTPS DOES NOT GUARANTEE:**│
├──────────────────────────────────┼─────────────────────────────────────┤
│ • Traffic between your browser   │ • Does NOT prove the owner is honest│
│   and that web server is         │ • Does NOT prove the site is not a  │
│   **encrypted with TLS**.        │   phishing scam!                    │
│ • Snoops on Wi-Fi cannot read    │ • 80%+ of active phishing websites  │
│   passwords in transit.          │   have valid HTTPS padlocks!        │
└──────────────────────────────────┴─────────────────────────────────────┘
```

<Callout type="warn">
**The Padlock Reality Check:** Today, anyone can obtain a 100% legitimate, free TLS certificate in 10 seconds from automated Certificate Authorities like *Let's Encrypt*. A criminal running `wellsfarg0-secure-login.com` will have a valid HTTPS padlock. **The padlock means the pipe is encrypted—it does not mean the person on the other end of the pipe isn't a thief!**
</Callout>

## 2. Inspecting URLs: Typosquatting and Homoglyphs

Attackers rely on the fact that humans read quickly and rarely inspect address bars character-by-character:

- **Typosquatting (URL Hijacking):** Registering common spelling typos of popular websites:
  - `g00gle.com` instead of `google.com`
  - `amazn.com` instead of `amazon.com`
  - `microsoft-security-verification.com` instead of `microsoft.com`
- **Homograph / Homoglyph Attacks:** Substituting lookalike characters from international alphabets (e.g., using the Cyrillic letter `а` (U+0430) which looks 100% identical to the Latin letter `a` (U+0061) on a monitor).

```
┌────────────────────────────────────────────────────────┐
│              THE LINK HOVERING DISCIPLINE              │
│                                                        │

│                                                        │

```

## 3. Web Threat Vectors: Drive-Bys, Malvertising, and Rogue Extensions

- **Drive-By Downloads:** Visiting a compromised website that exploits an unpatched vulnerability in your browser engine (Chromium, WebKit) or PDF plugin to silently install malware in the background without asking for permission.
  - **Defense:** Keep your browser updated to the latest version and enable the browser's **Sandbox Isolation** mode.
- **Malvertising:** Hackers pay for legitimate advertising slots on major news websites, but embed malicious redirection scripts inside the ad banner.
- **Rogue Browser Extensions:** Free "PDF converter" or "coupon finder" extensions frequently contain spyware that logs every password typed into your browser.

---

## Why This Matters in the Field

When helping users troubleshoot infected computers, you will find that over 80% of infections occur through web browsing traps.

Teaching users the link hovering discipline, demystifying the HTTPS padlock, and locking down browser extensions protects your organization from web-based intrusions.
