  - id: "q3"
    type: "short"
    prompt: "A ransomware crew encrypts a school's file server. Staff can reach the server but cannot open a single document. In one word, which CIA property has primarily failed?"
    acceptedAnswers: ["availability", "availabilty"]
    explanation: "Availability. The data still exists and has not been disclosed, but it is unusable to the people entitled to use it — that is exactly what availability protects. Modern ransomware often steals a copy first, which adds a confidentiality failure on top, but the reason work stopped is availability."
  - id: "q4"

      - "Availability failure"
      - "Integrity violation"
      - "Privilege escalation"
    correctIndex: 1
    explanation: "Nothing is read and nothing is changed — customers simply cannot reach a service they are entitled to reach. Denial of service attacks target availability by definition."

    correctIndices: [0, 1]
    explanation: "Encryption keeps data unreadable to anyone without the key, and access control decides who may see it — both are confidentiality controls. Backups exist so data can be restored, which is availability. Hashing proves a file has not been altered, which is integrity."
  - id: "q6"

    correctIndex: 1
    explanation: "The thief already has the hardware, so anything that guards the running machine is bypassed by removing the drive. Full disk encryption means the bytes on that drive are meaningless without the key. A BIOS password stops the machine booting, not the drive being read elsewhere."

    correctIndex: 1
    explanation: "Credentials being captured is the consequence, and it is a real confidentiality loss — but the question asks what failed first.     correctIndices: [0, 1, 3]
    explanation: "Security controls trade against each other constantly, and the first, second and fourth are all real tensions between confidentiality and availability.   - id: "q9"

    prompt: "Data being actively processed in a server's RAM is in which of the three states of data? Give the state only."
    acceptedAnswers: ["in use", "in-use", "use"]
    explanation: "In use. The three states are at rest (stored on disk), in transit (moving across a network), and in use (loaded into memory and being processed). In use is the hardest to protect, because the data must be decrypted for the processor to work with it."
  - id: "q10"

    options:

    correctIndex: 0
    explanation: "A backup answers 'can we get the data back', which is availability. Left unencrypted it makes confidentiality worse rather than better, because it creates a second copy to steal — which is why backup media is a common breach source."
  - id: "q11"

    prompt: "An insider with legitimate access quietly changes a handful of grades in the student information system. Which property failed, and why is this hard to detect?"
    options:

      - "Availability, because the correct grades are no longer obtainable"
      - "Integrity, and it is hard to detect because the change was made through authorised access and looks like normal use"
      - "Integrity, and it is hard to detect because the system does not store grades"
    correctIndex: 2
    explanation: "The data was altered without authorisation, so integrity failed. Detection is hard precisely because nothing anomalous happened at the access layer — a permitted account did a permitted operation. This is why integrity controls lean on audit logging and hashing rather than access control alone."
