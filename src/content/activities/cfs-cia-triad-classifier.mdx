Use this activity immediately after Intro to Cybersecurity.

## Scenario Set

Classify each incident using the primary CIA property impacted first:

1. Student records exposed in a public cloud bucket.
2. Payroll values altered by unauthorized script execution.
3. School portal unavailable during finals registration.

## Response Prompt

For each incident, provide:

- primary CIA category,
- one likely threat path,
- one immediate defensive action.

## Quality Bar

Strong answers are specific and avoid vague terms like "just secure it."

## Demo Prompt

Have learners defend why their first classification is primary even when multiple CIA properties are affected.
