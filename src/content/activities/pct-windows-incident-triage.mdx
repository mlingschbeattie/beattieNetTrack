Use this activity between the lesson and lab to force disciplined triage decisions.

## Ticket Snapshot

User report: "Laptop is slow, browser opens random tabs, and startup takes 8 minutes."

Recent context:

- Two unknown apps installed in the last week
- Defender real-time protection was turned off
- Startup list contains three unknown entries

## Decision Prompts

Respond in order using technician language:

1. Immediate containment: What should happen before deep investigation?
2. Evidence first: Which built-in Windows tools should be checked first and why?
3. Escalation threshold: What evidence would justify full reimage instead of cleanup?

## Quality Bar

A strong response is:

- sequenced from low risk to high risk,
- explicit about preserving evidence,
- clear about user communication before disruptive actions.

## Demo Prompt

In class, require students to justify each step as if they were writing an actual ticket note for another technician.
