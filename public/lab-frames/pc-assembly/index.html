Learning Objectives

This lab tests your understanding of:
  • CPU Socket Compatibility: Matching CPU to motherboard socket (LGA1700, AM5, AM4)
  • RAM Type Matching: DDR5 vs DDR4 compatibility with CPU and motherboard
  • Performance Requirements: Selecting appropriate components for specific use cases
  • Storage Standards: Understanding NVMe vs SATA SSD performance
  • Cooling Requirements: Matching cooler TDP rating to CPU heat output
  • Budget Management: Balancing performance with cost constraints
