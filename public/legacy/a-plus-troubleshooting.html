Troubleshooting & Repair

CompTIA A+ - Diagnostic methodology, hardware repair, software recovery, preventive maintenance

ELI5: Troubleshooting

Troubleshooting is like being a detective. You gather clues, narrow down suspects, test theories, and fix the root cause. The goal is not just to make it work—it's to find what went wrong so you can prevent it next time.

Diagnostic Methodology (CompTIA Standard)

The 7-Step Process
1) Identify the problem - Ask questions, document symptoms, gather logs 2) Establish a theory of probable cause - Use experience and knowledge to guess root cause 3) Test the theory to determine cause - Run diagnostic tools, test hypothesis 4) Establish a plan of action to resolve - Create fix plan, consider impact 5) Implement the solution or escalate - Apply the fix, monitor for issues 6) Verify full system functionality - Test everything to ensure problem solved 7) Document findings, actions, outcomes - Write detailed notes for future reference

Common Hardware Issues & Fixes

No Power
Check PSU, cables, power button, wall outlet
No Display
Reseat RAM, GPU, check monitor cable
Overheating
Clean fans/filters, reapply thermal paste
Beep Codes
POST errors (continuous = memory issue)
Intermittent Crashes
Bad RAM, power supply failing, overheating
Slow Performance
CPU/GPU pegged, RAM full, disk fragmented/dying

Software Troubleshooting Tools

Task Manager (Windows)
Monitor processes, CPU, memory, startup programs
Device Manager
Check drivers, disable hardware, update drivers
Event Viewer
View system, security, application logs
Disk Management
Partition, format, resize drives
System Restore
Roll back to previous stable state
Safe Mode
Boot with minimal drivers/services

Recovery & Backup Strategies

File Backup
Copy important documents, photos, etc.
Image Backup
Full system snapshot (whole drive)
3-2-1 Rule
3 copies, 2 different media, 1 offsite
Incremental Backup
Only changes since last backup (fast)
Cloud Backup
OneDrive, Google Drive, Backblaze
Test Restore
Actually verify backups work

Common Software Issues

Slow Boot
Too many startup apps, failing disk
Application Crash
Check updates, logs, reinstall if needed
Blue Screen
Driver issues, memory faults, hardware
No Internet
Check IP config, DNS, router status

Printer Troubleshooting

Paper Jam
Remove paper gently, check rollers
Low Ink / Toner
Replace cartridge, run calibration
Wrong Driver
Install correct model driver
Print Spooler
Restart service when jobs are stuck
Connectivity
Check USB, Wi‑Fi, or network IP
Ghosting / Streaks
Clean drum, replace toner/ink

Mobile Device Issues

Battery Drain
Check background apps, brightness
Overheating
Close apps, remove case, cool down
Storage Full
Clear cache, remove unused apps
No Signal
Toggle airplane mode, check SIM
App Crashes
Update or reinstall app
OS Updates
Check available updates and reboot

Preventive Maintenance

Regular Tasks
Weekly: • Clear temp files (Disk Cleanup) • Check Task Manager for runaway processes Monthly: • Defragment drives (HDD only, not SSD) • Update Windows and drivers • Scan for malware Quarterly: • Clean internal dust (fans, heatsinks) • Check drive health (SMART diagnostics) • Review backup status Annually: • Replace thermal paste on CPU • Upgrade OS if available • Audit and remove unused software

Exam Critical Facts

What You Must Know
• Always document your work (dates, times, actions) • Follow diagnostic methodology in order • Don't assume—test every theory • Never give up troubleshooting without escalation • Keep users informed of progress • Prioritize data safety before experimenting • Know the difference: symptom vs cause • Always back up before major changes
