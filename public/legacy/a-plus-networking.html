Networking Essentials

CompTIA A+ - OSI model, TCP/IP, IPv4/IPv6, wireless, and troubleshooting

ELI5: What is Networking?

Networking is how computers talk to each other. The internet is the biggest network. Your home WiFi is a smaller network. Everything follows rules (called protocols) so they all understand each other.

OSI Model Layers

Layer 7: Application
HTTP, DNS, FTP, SSH, SMTP
Layer 6: Presentation
Encryption, compression, translation
Layer 5: Session
Session management, dialogs
Layer 4: Transport
TCP, UDP (ports, reliability)
Layer 3: Network
IP (IPv4, IPv6), routing
Layer 2: Data Link
MAC addresses, Ethernet, switching
Layer 1: Physical
Cables, signals, hardware

TCP/IP Basics

IPv4
32-bit address (192.168.1.1), 4.3 billion addresses
IPv6
128-bit address (2001:db8::1), vast address space
DHCP
Automatic IP address assignment
DNS
Translates names to IPs (google.com → IP)
TCP
Reliable, ordered delivery (email, web)
UDP
Fast but unreliable (video, gaming)

Wireless Standards

802.11a/b/g
Older standards (phased out)
802.11n (WiFi 4)
2.4/5 GHz, MIMO, up to 600 Mbps
802.11ac (WiFi 5)
5 GHz only, up to 3.5 Gbps
802.11ax (WiFi 6)
2.4/5/6 GHz, OFDMA, 9.6 Gbps
Security: WPA3
Latest encryption (WPA2 still common)

Subnetting Quick Basics

Tiny Reference
/24 = 255.255.255.0 → 256 addresses (254 usable) /25 = 255.255.255.128 → 128 addresses (126 usable) /26 = 255.255.255.192 → 64 addresses (62 usable) /27 = 255.255.255.224 → 32 addresses (30 usable) Network address = all host bits 0 Broadcast address = all host bits 1

Exam Facts

What to Know
• Remember "Please Do Not Throw Sausage Pizza Away" (OSI layers) • Common ports: 80 (HTTP), 443 (HTTPS), 22 (SSH), 53 (DNS) • Private IP ranges: 10.x.x.x, 172.16–31.x.x, 192.168.x.x • Subnet mask determines network size (/24 = 256 addresses) • DHCP pool: range of IPs available • Wireless: 2.4 GHz (further range) vs 5 GHz (faster, less range) • MAC address is Layer 2; IP address is Layer 3
