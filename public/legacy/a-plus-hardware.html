Hardware Fundamentals

CompTIA A+ Core 1 - Essential hardware components and architecture

ELI5: What is Computer Hardware?

Hardware is the physical stuff you can touch in a computer. It's like the organs in a body—each has a specific job, and they all work together to make the computer run.

Practical Exercises

Key Components

CPU (Processor)
The brain—does all the calculations
RAM (Memory)
Fast, temporary storage for running programs
Motherboard
The main circuit board connecting everything
Power Supply Unit
Converts AC to DC power for components
Storage (HDD/SSD)
Permanent storage for files and OS
GPU (Graphics Card)
Handles display rendering (optional)

CPU Characteristics to Know

Clock Speed (GHz)
How many operations per second (higher = faster)
Cores
Number of independent processors
Cache
Ultra-fast memory on the chip
TDP (Thermal Design Power)
Heat output, measured in watts

RAM Deep Dive

DRAM vs SRAM
Dynamic (common) vs Static (fast, expensive)
DDR, DDR2, DDR3, DDR4, DDR5
Generations of RAM (newer = faster)
Capacity (GB)
How much data can be stored temporarily
Speed (MHz)
Access speed; higher is better

Common Ports & Peripherals

USB 2.0/3.x/4
Data + power; 3.x/4 are faster
HDMI / DisplayPort
Digital video (DP often supports higher refresh)
Ethernet (RJ‑45)
Wired networking port
Audio (3.5mm)
Mic/line‑in/headphones
Thunderbolt
High‑speed data/video over USB‑C
Bluetooth / Wi‑Fi
Wireless peripherals and networking

Laptop & Mobile Hardware

SO‑DIMM RAM
Smaller memory modules for laptops
M.2 SSD
Common laptop storage upgrade
Battery Types
Lithium‑ion, Lithium‑polymer
Laptop Screens
TN vs IPS, resolution basics
Docking Stations
Expand ports and displays
Touch & Stylus
Digitizers and touchscreen support

Display Standards & Types

LCD (Liquid Crystal Display)
Uses backlight and liquid crystals; common and affordable
LED (Light Emitting Diode)
LCD with LED backlight; thinner, energy efficient
IPS (In-Plane Switching)
Best color accuracy and viewing angles
TN (Twisted Nematic)
Fastest response time; poor viewing angles
VA (Vertical Alignment)
Best contrast ratio; middle ground
OLED (Organic LED)
Per-pixel lighting; perfect blacks, vibrant colors
AMOLED
Active-matrix OLED for mobile devices
Quantum Dot / QLED
Enhanced color and brightness via nanocrystals

Resolutions & Features

1080p (Full HD)
1920×1080 pixels; standard desktop resolution
1440p (2K/QHD)
2560×1440 pixels; popular for gaming
4K (Ultra HD)
3840×2160 pixels; 4× Full HD detail
8K
7680×4320 pixels; emerging standard
Refresh Rate (Hz)
60Hz standard, 120Hz/144Hz/240Hz gaming
Response Time
1ms-5ms; lower = less motion blur
HDR (High Dynamic Range)
Better contrast and color depth (HDR10, Dolby Vision)
Aspect Ratio
16:9 standard, 21:9 ultrawide, 32:9 super ultrawide

Sound Card

USB Expansion

Know for the Exam

Core Facts
• A CPU with 4 cores and 8 threads can handle 8 operations at once • RAM is volatile (loses data when powered off) • DDR4 is standard in 2020s (DDR5 emerging) • Thermal paste helps CPU-to-heatsink contact • Case fans pull cool air in, push warm air out • Wattage rating on PSU should be 120-150% of total system draw
