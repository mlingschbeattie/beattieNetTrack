Learning Objectives

This lab tests your understanding of:
  • Boot Configuration: Setting boot mode, secure boot, and boot priority
  • Virtualization: Enabling Intel VT-x/AMD-V for virtual machines
  • Memory Performance: Configuring XMP/DOCP profiles for RAM
  • Storage Controllers: Understanding AHCI vs RAID modes
  • Power Management: Configuring fan profiles and power states
  • Security Features: Managing Secure Boot and legacy support
